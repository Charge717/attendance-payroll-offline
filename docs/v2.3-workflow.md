# v2.3 月結保存與資料保護

本版維持單一 HTML 離線使用，預設薪資計算方式不變；舊 JSON 備份可匯入。

## 月結保存

1. 在「薪資結算」選擇月份，計算並核對結果。
2. 點「保存並鎖定月結」，確認後保存該月員工、薪資結果、公司規則及時間。
3. 鎖定月份的結算畫面、薪資報表、薪資單與 Excel 使用保存結果。後續調薪或改公司規則不會改寫該份薪資。
4. 需要修改該月出勤、假勤或月結調整時，先點「填寫原因並重新開啟」。取消或空白原因不會開啟。
5. 重新開啟後畫面使用目前資料重算；再次保存會新增版本。展開「月結保存紀錄」可查看時間、原因與各版實發合計。

所有歷史版本保留在 JSON 備份中；一般薪資單與 Excel 輸出採最新鎖定版本。重新開啟期間採目前資料。歷史版本目前僅顯示保存摘要，沒有選取舊版重新列印的介面。

「鎖定」是本機程式的操作保護，沒有密碼或防竄改簽章。員工資料可為未來月份調整；直接刪除員工可能連帶刪除出勤，因此會受到月份鎖定檢查。報表異常檢查與月結調整表仍反映目前來源資料，薪資輸出則依鎖定快照。

## 公司規則生效月份

選擇生效月份後儲存，確認畫面列出變更。該月份起採用新設定；更早月份保留首次設定前的既有公司規則。再次儲存同一生效月份會取代該月份的設定；已鎖定薪資仍維持原快照。

規則歷程與月結快照一併包含於 JSON 備份。重設台灣預設也依畫面選擇的生效月份套用。

## 匯入與復原

匯入先驗證資料結構、員工識別碼、日期、出勤時間、規則版本及月結結果，顯示紀錄筆數與月份。確認覆蓋前可下載現有 JSON；程式也保留一份匯入前資料。按「復原上次匯入前資料」會先下載目前資料，再恢復該份資料。

復原資料只保留最近一次匯入前的狀態，也存在同一瀏覽器。清除瀏覽器資料會失去原資料與復原資料，因此仍需將 JSON 存到瀏覽器以外。儲存空間不足時停止匯入，原資料保留。

## English summary

v2.3 saves immutable monthly payroll revisions, requires a reason to reopen a locked month, and applies company rules by effective month. Reports, payslips and workbook payroll output use the latest locked revision. JSON restore validates and previews records before replacing data and retains one pre-import recovery copy. Export JSON backups regularly; browser recovery storage is not an independent backup.
